# Фінальний чекліст

Практична робота №17 · Student Task Manager · Руслан Махмадов, 31 КНС

Представлена розширена версія після самостійної роботи. Код перевірено з чистого клону GitHub, на базі коміту `f08d8b0`.

| Пункт | Стан | Підтвердження |
| --- | --- | --- |
| Код та структура репозиторію | Готово | `server/` — поточна версія, `app/` — MVP №16, `docs/` — матеріали курсу, `presentation/` — фінальні слайди. |
| README та чистий запуск | Готово | Python 3.12, нове віртуальне середовище, встановлення з `requirements.txt`, запуск Uvicorn. Головна сторінка повернула HTTP 200. Команди перевірено в Linux. |

## Стан вимог

| Стан | Можливості |
| --- | --- |
| Реалізовано | Обліковий запис, вхід і вихід, особистий список, створення, редагування, зміна стану та видалення, SQLite, пошук, фільтри, сортування, позначення прострочених записів. |
| Частково реалізовано | Категорії доступні зі списку готових значень. Адаптивні правила є в CSS, візуальна перевірка вузького екрана ще потрібна. |
| Заплановано | Нагадування, власні категорії, відновлення пароля та підтвердження пошти. |

Попередні діаграми та прототип відображають проєктний задум. У поточній реалізації є окремий екран входу й реєстрації, пошук і фільтри над списком, а створення та редагування відкривають спільну форму.
