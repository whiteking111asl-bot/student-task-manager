# MVP Student Task Manager

Руслан Махмадов · 31 КНС · Практична робота №16

Мета — дати студенту змогу вести список навчальних робіт із дисциплінами, строками здачі та статусами. Реалізація спирається на [вимоги](requirements.md), [UC-01](use-case.md) та [прототип](prototype.md).

| Код | Функція |
| --- | --- |
| MVP-01 | Показати актуальний список або повідомлення про відсутність записів |
| MVP-02 | Додати активне завдання з назвою, дисципліною та датою |
| MVP-03 | Редагувати вибране завдання зі збереженням його ідентифікатора |
| MVP-04 | Позначити завдання виконаним або повернути до активних |
| MVP-05 | Видалити вибраний запис |
| MVP-06 | Переглядати всі, активні або виконані записи |
| MVP-07 | Відхилити порожні й пробільні назви при створенні та редагуванні |

Дані зберігаються в localStorage браузера. Вхід, синхронізація між пристроями, сповіщення та сортування за строком відкладено. Застосунок відкривається з app/index.html. Команди клонування наведено в [README](../README.md).

## Результати перевірок

Виконано JavaScript із фактичного HTML у Node.js з імітацією DOM і localStorage. Перевірено обробники форми та кнопок і зміни списку. Запуск браузерного інтерфейсу в цьому середовищі заблокував збій Chromium під час старту.

| № | Перевірка | Очікуваний результат | Фактичний результат | Статус |
| --- | --- | --- | --- | --- |
| 1 | Запуск за README | Файл відкривається у браузері й показує початковий стан | Клонування і шлях перевірено. Скрипт показав «Завдань поки немає» у тестовому DOM. Chromium не запустився | Заблоковано |
| 2 | Створення | Новий запис з’являється у списку | Список змінився з порожнього на один запис «Звіт» | Пройдено |
| 3 | Створення без назви | Запис не додається, є повідомлення | Список залишився з одним записом. Отримано «Введіть назву завдання» | Пройдено |
| 4 | Назва з пробілів | Запис не додається | Після введення трьох пробілів у списку залишився тільки «Звіт» | Пройдено |
| 5 | Редагування | Змінюється вибраний запис без дублювання | «Практична» стала «Практична 16». У списку залишилося два записи | Пройдено |
| 6 | Порожня назва при редагуванні | Попередні дані зберігаються | Назва «Практична 16» залишилася у списку, форма залишилася в режимі редагування | Пройдено |
| 7 | Зміна стану в обидва боки | Запис переходить між активними й виконаними | «Звіт» з’явився у виконаних. Після повернення фільтр виконаних став порожнім | Пройдено |
| 8 | Видалення | Видаляється вибране завдання | Після видалення «Звіту» залишився «Готова ПР16» | Пройдено |
| 9 | Три фільтри | Режими показують записи відповідного стану | «Усі» показав обидва записи, «Активні» — «Практична 16», «Виконані» — «Звіт» | Пройдено |
| 10 | Редагування під фільтром | Змінюється правильний запис, фільтр зберігається | В активних «Практична 16» стала «Готова ПР16». «Звіт» залишився з попередньою назвою | Пройдено |

Додатково повторна ініціалізація скрипту з тим самим імітованим сховищем повернула один запис «Готова ПР16».
