# Опис програмного продукту

## Назва
Student Task Manager — менеджер навчальних завдань студента.

## Проблема
Студентам складно тримати в одному місці домашні завдання, терміни здачі та поточний стан виконання. Через це можна пропустити дедлайн або забути про важливу роботу.

## Цільова аудиторія
Студенти коледжів та університетів, які виконують завдання з декількох дисциплін.

## Мета продукту
Допомогти користувачу організувати навчальні завдання, бачити їхні терміни та контролювати виконання.

## Основні функції
- додавання навчального завдання;
- перегляд переліку завдань;
- позначення виконаних завдань;
- збереження терміну виконання;
- фільтрація завдань за статусом.

## Склад MVP
Мінімальна версія продукту має дозволяти створювати, переглядати, редагувати й завершувати завдання, а також показувати дату здачі. Це опис запланованого MVP; фактична реалізація залежить від стану репозиторію.
