# Student Task Manager

Навчальний проєкт планувальника для студентів, які хочуть зібрати завдання з різних дисциплін в одному місці та бачити строки здачі й статус виконання. Поточна версія — клікабельний прототип із демонстраційними даними.

## Що працює

- Перегляд списку завдань і даних вибраного запису.
- Перехід до форми нового завдання, імітація збереження та скасування.
- Повернення до списку з екрана перегляду.

Використано **Figma Design і Prototype** для трьох екранів і п’яти переходів, **Markdown і Mermaid** для документації та **Git і GitHub** для її збереження.

## Отримання та запуск

Для клонування потрібен Git. Для демонстрації потрібен браузер з доступом до інтернету.

```bash
git clone https://github.com/whiteking111asl-bot/student-task-manager.git
cd student-task-manager
```

Відкрийте `README.md` у клонованій папці й перейдіть за посиланням нижче. Figma відкриє екран «Мої завдання». Для цієї версії весь запуск відбувається у браузері.

[Відкрити клікабельний прототип у Figma](https://www.figma.com/proto/VGoGwDsLOAimlexmmisqRK/Untitled?page-id=0%3A1&node-id=2-2&starting-point-node-id=2%3A2&scaling=min-zoom&content-scaling=fixed)

## Приклад використання

Натисніть «Нове завдання». У формі вже є демонстраційні назва «Звіт», дисципліна «Інформатика» й дата 2026-11-20. Натисніть «Зберегти», відкрийте картку «Звіт» і звірте дату та статус «Не виконано». Кнопка «До списку» повертає на початковий екран.
