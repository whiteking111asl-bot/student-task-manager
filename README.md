# Student Task Manager

Student Task Manager допомагає студентам вести список навчальних робіт, дисциплін і строків здачі. Робочий MVP на HTML, CSS і JavaScript дозволяє додавати, переглядати, редагувати й видаляти завдання, змінювати статус та фільтрувати список.

## Запуск

Для клонування потрібен Git, для запуску — сучасний браузер. Залежностей установлювати не потрібно.

```bash
git clone https://github.com/whiteking111asl-bot/student-task-manager.git
cd student-task-manager
```

Відкрийте `app/index.html` у браузері з клонованої папки.

## Приклад

Введіть «Звіт», «Інформатика» та дату 2026-11-20. Натисніть «Додати завдання» і перевірте появу запису. Позначте його виконаним та виберіть фільтр «Виконані». Далі поверніть завдання до активних, відредагуйте назву й видаліть запис.

Дані зберігаються в localStorage поточного браузера. Вхід, синхронізація, сповіщення та сортування за строком відкладені.
